# V1.1（1.1.0）

- 新增 GitHub 检查更新：启动后后台检查并自动下载更高的正式版本，设置中可关闭，也可手动检查、取消和重试；关于页增加检查入口。
- 更新下载及安装前验证 SHA-256。有未完成视频任务时拒绝安装；安装前确认、停止微信接入并恢复代理，然后退出并打开安装向导。保留下载视频和设置。
- 保留 Win10 22H2 x64 / Win11 x64 适配与批量删除功能。用户于 2026-10-19 确认此前 Win10 兼容重构版可以启动并正常使用；该反馈不代表新增更新器和全部专项兼容测试已通过。
- 1.0.x 用户需手动安装一次 1.1.0，之后可使用更新器。更新器仅接收正式发布；预发布、旧版本、缺失校验文件或校验失败的文件不会自动安装。
- 安装包未签名。更新机制与发布附件约定见 `docs/UPDATES.md`，验收范围见 `docs/VALIDATION.md` 与 `docs/WINDOWS10.md`。

## 1.0.1-rc.1 本地测试版

- “导入旧目录”左侧新增“批量选择”：点击卡片多选，显示勾选标记与已选数量，可全选/取消全选当前搜索结果，点击“删除记录”默认保留文件，勾选确认框中的“同时删除本地文件”才执行永久删除。搜索或刷新会清空选择，避免误删隐藏项目；部分失败时保留失败记录并可重试。
- “已下载”卡片右上角新增“…”菜单：仅删除记录，或删除记录并永久删除本地视频文件。两者均有确认框，默认选中取消。
- 删除状态持久化，刷新、重启、目录扫描及旧任务通知不会自动恢复记录；新下载仍可显示。文件被占用或删除失败时保留记录；缺失文件可清理记录；不删除目录、链接或其他文件。
- 最低安装版本降为 Windows 10 22H2 x64（19045），为标题栏与透明背景增加支持检查。不支持桌面透明背景时使用实色主题。
- Windows 10 尚无实机或虚拟机验证，属于兼容候选；参见 `docs/WINDOWS10.md`。当前用户的旧版安装与下载进程未被替换或中断。
- 本轮服务与完整构建检查已通过，隔离界面已验证菜单、两种确认框和取消行为；实际文件删除由服务夹具验证。新媒体库索引不兼容旧版，请停止旧版并退出后再更新，勿用旧版覆盖运行。

此候选未发布到 GitHub，安装包未签名。历史验收记录见 `docs/VALIDATION.md`。

## 1.0.0 历史说明

EVEING Lumiven 1.0.0 是免费、源码公开的 Windows 11 x64 视频号下载与媒体管理应用。该版不包含 Windows 10 适配。

- WinUI 玻璃界面、下载任务与历史记录。
- 保留微信视频号页面下载入口；保存结果在软件内查看、播放和定位。
- 用户选择下载目录；安装/卸载保留用户数据。
- 显式启用证书和当前用户代理，停止时恢复原代理设置。
- 基于 nobiyou/wx_channel，移除 NetFilter SDK 商业驱动/API；EVEING 新增代码 GPL-3.0-only。

安装包、对应源码归档和 SHA256SUMS 同时附上。安装包尚未进行代码签名。完整许可、来源与实际测试记录包含在源码中；已实测 Windows 11 10.0.26200 与微信 4.1.15.13，其他构建的兼容性仍需验证。
