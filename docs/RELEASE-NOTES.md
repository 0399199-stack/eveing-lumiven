# V1.2.0 · 正式版

## 新增功能

- 新增“视频解析”页面：抖音分享短链接、小红书视频笔记与分享短链接支持粘贴链接或整段分享文案，解析后直接下载，无需填写 Cookie。作品受平台限制时会明确提示失败。
- 两个平台下载完成后自动收录到“已下载”，支持封面、标题/作者搜索、内置播放、文件定位与重启保留。优先使用平台可提供的无水印源，不抹除画面中已有水印。
- “下载中”更名为“视频号下载”，新增使用帮助、证书确认及下载入口教程。
- 设置新增浅色、深色、跟随系统和中英文切换；左下角显示当前版本。
- 新增“视频号异常修复”，可停止本软件接入并恢复其连接设置；仅处理 Lumiven 自己保存的代理/证书状态，Windows 安全提示仍需用户确认。
- 新增启动使用须知与免费声明、“不再显示此提示”和官方 GitHub 按钮；视频解析支持清除已结束的任务记录，保留视频和媒体库。
- 更新页面及安装确认框显示新版功能说明。继续使用官方 GitHub 检查更新、后台下载与 SHA-256 校验。

## 修复与改进

- 修复下载完成与媒体库扫描同时发生时漏刷新、记录写入失败后状态不一致、截断响应被误判完成的问题。
- 小红书主源失败时尝试备用源；补齐超时、取消及实际画质记录。修复链接紧贴中文时的识别。
- 修复含特殊字符文件名的定位、文件放回原路径后仍无法直接播放、旧播放器回调影响新视频及播放器背景透字。
- 优化主题颜色一致性、提示文字和列表交互；保留原有媒体库与批量删除能力。

## 安装与升级

- 下载 `EVEING-Lumiven-Setup-1.2.0-x64.exe`。兼容目标为 **Windows 10 22H2 x64（19045）与 Windows 11 x64**，不支持更早 Win10、32 位或 ARM64。
- Windows 10 保留标题栏、透明效果的兼容降级；安装包自带 .NET 和 Windows App SDK，无需另装运行环境。此前 Win10 基础使用由维护者实机确认，本次新增功能未在 Win10 实机重新完整验收，兼容记录见源码 `docs/WINDOWS10.md`。
- **1.1.0 / 1.1.1 用户**可在软件内检查更新；开启自动更新时启动后会检查并后台下载，校验完成后点击“安装更新”并确认向导。1.0.x 用户请手动安装本版。
- 更新保留下载视频、设置和记录；安装前请完成下载并停止微信接入。安装包未进行开发者代码签名，附件提供 `SHA256SUMS` 完整性校验及对应源码。
