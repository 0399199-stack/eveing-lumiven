## 下载内核验证（2026-10-20）

维护者先选择 [yt-dlp](https://github.com/yt-dlp/yt-dlp)，并在抖音匿名解析失败后授权对比 [F2](https://github.com/Johnserf-Seed/f2)。尚未把这些实验依赖接入正式程序。

| 实验 | 结果 |
| --- | --- |
| yt-dlp 2026.08.19，维护者提供的小红书视频 | 解析并下载成功，720×1280、24.134 秒、6,271,439 字节；FFmpeg 全文件解码退出码 0。未使用浏览器 Cookie。 |
| yt-dlp 2026.10.10.233141 官方 nightly，同一小红书链接 | 解析成功，返回三种格式；nightly 本身未做完整下载验收。 |
| 上述两版 yt-dlp，维护者提供的抖音精选页链接转换为对应 `/video/` 地址 | HTTP 403，提示需要新鲜 Cookie；没有下载成功文件。 |
| F2 提交 `f6be8c0ffba9a127075bbeafe4838716650b6325`，同一抖音视频 | 匿名调用返回 HTTP 200、正文 0 字节，解析失败。没有读取用户浏览器或登录状态。 |
| 匿名抖音视频网页检查 | 页面只有验证脚本和匿名 nonce Cookie，没有视频详情数据；不能将 HTTP 200 视为解析成功。 |

以上各为单个用户提供的视频样例，不代表所有链接、画质或网络条件。分享链接中的访问参数、下载视频和原始响应仅在被 Git 忽略的本地 QA 目录；不进入公开仓库。
