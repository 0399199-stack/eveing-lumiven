## 明确的测试边界

- Windows 10 基础启动和使用由用户实机确认；本次无法继续 Win10 专项测试，作为兼容测试范围保留。详见 [Windows 10 记录](WINDOWS10.md)。不把 Windows Server CI 等同于 Win10 或干净 Win11 用户设备测试。
- 当前 Windows 11 实机已有运行环境；自包含依赖审计和 CI 干净 Runner 安装/升级/卸载提供额外证据，但不是所有干净 Win11 设备、显卡与微信版本的保证。
- 1,000 条合成媒体记录、5 项模拟进度、66.78 秒：渲染回调中位数 16.66ms、p95 19.59ms、最大 98.47ms；UI 计时器出现 1 次超过 100ms 的间隔，最大 131.64ms。已插桩 UI 回调最大 24.27ms。见 [原始性能结果](verification/stable-20261019/performance.json)。这些数据不是 GPU 呈现帧率或真实五路下载，也不能证明所有点击反馈/界面阻塞低于 100ms；原计划的严格性能目标没有全部证实。
- 多显示缩放组合、所有编码、所有指定画质和新版微信页面未全部覆盖。遇到原生播放器不支持的编码可使用系统播放器。
- 证书删除可能需要 Windows 本人确认；异常退出恢复测试包含这一步，不宣称全程无提示。
- 安装包未进行开发者代码签名；SHA-256 用于完整性校验，不代替代码签名。
