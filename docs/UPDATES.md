# GitHub 软件更新

当前正式版本为 V1.2.0，1.1.0 / 1.1.1 用户可通过原更新器识别并升级。无需自建下载站；更新来源固定为 `0399199-stack/eveing-lumiven` 的公开 GitHub Releases，不需要用户登录或提供令牌。

## 使用方式

- 默认启动后延迟检查，在后台下载版本号更高的正式版。设置 → 软件更新可关闭自动检查/下载，也可手动检查、下载、取消及重试；关于页也提供检查入口。
- “打开 GitHub”直接打开项目主页；发现新版时另显示该版本的发布说明链接。
- V1.2.0 增加软件内更新说明：发现新版时读取该 Release 的正文，在设置页及安装确认框展示；按纯文本显示，不执行 HTML。空说明使用提示，过长正文截断并保留 GitHub 完整说明入口。旧 1.1.x 更新器仍可下载升级，但软件内说明面板需升级至 1.2.0 后才能使用。
- 下载完成后显示“安装更新”。安装需要用户点击并确认，不会静默覆盖正在运行的软件。有未完成视频任务时拒绝安装；正常安装先停止接入并恢复代理，再退出应用打开安装向导。用户完成安装后重新打开软件。
- 安装前再次核对 SHA-256；缓存文件被改动、断网、下载不完整、校验失败时均不会执行。校验值检查完整性，不等同于开发者代码签名。
- 只从项目本身的 HTTPS Release 地址获取安装包，支持 GitHub 官方资源域名跳转。安装包缓存位于 `%LOCALAPPDATA%\EVEING\Lumiven\updates`，不写入视频目录；退出时取消正在进行的更新下载。
- GitHub 网络不可达、限流或超时会在设置页说明，可稍后重试，不影响已下载视频的使用。启动检查不弹错误对话框。
- 1.0.x 没有更新器，需要先手动安装一次 1.1.0，之后才能使用此功能。当前版本及更低版本不会触发下载；草稿、预发布版和不规范版本标签不会自动安装。

## 后续发布约定

每次发布先递增版本，例如 `1.1.1` 或 `1.2.0`；不要以同版本重新上传来推送更新。正式标签使用 `v1.2.0`，附上：

1. `EVEING-Lumiven-Setup-1.2.0-x64.exe`
2. `EVEING-Lumiven-Source-1.2.0.zip`
3. `SHA256SUMS`，每行格式为小写 SHA-256、两个空格和完整文件名。

更新器按数字比较版本，识别 `v1.2.0` / `V1.2`；安装包文件名始终使用三段版本号。它选取列表中最高的正式版本；如果该版本缺少安装包或校验文件，会提示发布尚未完整，不会回退到其他附件或下载源。若 GitHub 提供附件 `digest`，它必须与 `SHA256SUMS` 一致。

发布工作流已支持规范版本标签，仍要求实际验收记录通过。将版本标记为正式发布后，旧版 1.1.0 用户下次启动时会检查并下载。预发布不会推送给普通用户。
