# EVEING Lumiven v1.0.0 预发布

这是供公开测试的 Windows 11 x64 版本，免费提供并公开对应源码。正式版验收尚未完成，请勿将其视为稳定版。Windows 10 暂未验证。

在 Windows 11 10.0.26200、微信 4.1.15.13 上，已实测视频号页面加载、注入下载入口、单条下载、从个人主页批量下载两条视频、保存后在媒体库播放，以及停止接入后恢复原代理并移除本软件证书。构建测试覆盖任务持久化、断网、端口冲突、写入失败和 5/2 路并发夹具。

指定画质、成功接入后的真实异常退出恢复、磁盘满/目录权限拒绝、不同显示缩放和完整交互性能仍待验收。实际检查记录与限制见源码中的 `docs/VALIDATION.md`。若微信更新了页面或接口，下载入口可能需要适配。

安装包 `EVEING-Lumiven-Setup-1.0.0-x64.exe` 未进行代码签名。安装前可用 `SHA256SUMS` 核对文件；`EVEING-Lumiven-Source-1.0.0.zip` 是对应源码。首次启用时会说明本机代理和根证书处理，停止接入时会恢复原设置；Windows 显示证书确认时请阅读后自行决定。

基于 [nobiyou/wx_channel](https://github.com/nobiyou/wx_channel) 等开源项目开发。EVEING 新增代码使用 GPL-3.0-only，保留上游许可与版权；不得用于无权保存的内容。本项目与腾讯、微信及上游作者无官方隶属关系。
